# Prompsit CLI skills

Packaged agent workflows for Prompsit CLI.

- `prompsit-setup`: install and authenticate.
- `prompsit-translate`: translate text and documents.
- `prompsit-evaluate`: evaluate translation quality and tag preservation.
- `prompsit-score`: score parallel corpora.
- `prompsit-annotate`: annotate monolingual data.
- `prompsit-localize`: apply an editorial localization workflow over machine translation.

The CLI installs compatible skills on first interactive launch when the user accepts the prompt. The current runtime requirement and package contents are owned by `package.json`; command syntax is owned by `prompsit --help`.
